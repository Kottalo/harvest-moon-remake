# NPCs and dialogue

- `game/npc/` owns ordinary villager schedules, movement and greetings. Generate `npc_catalogue.json` offline with `tools/import_npc_schedules.py` from the source cue table, native area routes and packed ANI catalogue. Use the source map/place pairs, weekday/season schedule variants and one shared villager scene. Story-dependent actors and cue actions are deferred. Anchor the 0.2 m grid at the visible soil edge (-4.4,-1.6) so one soil cell is exactly 2x2. Native AStar2D uses Manhattan distance and four-connected unit-cost edges; build in physics batches using layer 8 support, layer 1 capsule checks and the shared shadow footprint. Check mid-edge support and thin walls and replan after new obstacles. World owns area and clock integration. Run `tools/verify_npc_navigation.gd` and `tools/verify_npc_roster.gd` for route, collision and cast regressions.
- The schedule supplies one presence lookup per actor. Loaded actors report live area-local positions; unloaded actors report their selected schedule area and first route point. Dialogue receives nearby visible people and same-floor indoor awareness separately from the stricter conversation and witness radius. The supermarket can report co-presence without an exact position when a display blocks sight.
- Z starts live nearby dialogue (choose 交谈 for merchants). Enter types/sends, Escape ends; walking away closes the conversation. Speech bubbles follow both player and NPC. Player messages can queue while a response streams, and the world keeps running. Replies use live nearby guests and at most two speakers per message. Group replies can only retrieve prior speech known to their whole audience. An unsolicited topic-based contribution is limited to one per conversation. The history records a player message at send time and an NPC reply on completion.
- NPCs move one adjacent grid cell at a time, on one world axis per step. Prefer straight and single-turn routes through the four-connected graph when available. Otherwise use Manhattan A* to find the minimum step count, then minimize heading changes across routes of that length. On contact, refresh nearby cells and replan from the actual body position on the same physics tick. Start a batched rebuild immediately if the local update cannot find a route. Retry after a short pause only when the rebuild finds no route. Keep the chosen endpoint until arrival or a schedule change.
- The desktop Pi Agent worker is launched on first dialogue. Set up Node.js 22.19+ and run `npm ci --prefix game/npc/dialogue/pi --ignore-scripts` from the project directory. The game uses Node from PATH or an executable path in `user://pi-node.path`. It uses `DEEPSEEK_API_KEY` or the existing `user://deepseek.key` and passes it through stdin only. Pi runs DeepSeek Flash without tools, using current local perception and witnessed history. F1 shows per-run provider-reported input, cache hits and output, plus counts of submitted and reported requests. Closing midstream can leave usage unreported. Idle NPC schedules are local and issue no model requests.
