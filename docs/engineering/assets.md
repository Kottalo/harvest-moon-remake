# Assets and rendering

## Packed images and rendering

- All game/source PNGs are now packed by Free Texture Packer CLI. Read tools/texture_packer/README.md before changing asset layout. That directory's .gdignore excludes source originals, generated independent frames and npm dependencies from Godot imports/exports. Runtime uses 88 packed PNGs, semantic AtlasTexture .tres views, frame catalogues and native .scn resources. Preserve original 128/256 canvas sizes, per-pose margins, timing, alpha/STP and field/item pivots. The existing original PNG paths in older instructions now refer to offline source material or their adjacent .tres replacements. Keep the original sources in tools/texture_packer/source and generated frames out of game/.
- Shader samplers receive the full atlas RID: map/soil/motion shaders must use atlas_binding.gd and atlas_sampling.gdshaderinc, while Sprite3D handles AtlasTexture UVs itself. Loose-item MultiMesh UVs are explicitly transformed into their atlas region. Do not apply both transformations to a Sprite3D. StandardMaterial3D legacy scenery uses matching uv1_scale/offset. Source geometry, per-triangle UVs and VRAM-copy tables remain unchanged. Frame texture cache keys include margins because 128 shared cropped images have different ANI canvas offsets. verify_atlases.gd checks all 46 native scenes and 1691 shader bindings; verify_packed_frames.gd checks all 6212 actual action draws. Source verifiers use pack_textures.source_path only offline; never add runtime references to tools/.
- `game/rendering/`: shared source-model and player drawing shaders. Preserve source backface culling, but use normal continuous 3D depth for solid scenery: writing one average depth per face caused stair/terrain distortion. Only the whole player uses its ground-relative source hand point for depth, independent of pose pixels. Keep depth testing enabled. Preserve PS1 STP classification and blend mode separately from opaque texels; transparent effects do not write depth. Neutral additive-black primitives keep collision but have no drawing. Run GPU checks in `tools/verify_render_order.gd` through Godot AI plus native checks after rebaking. The user requested Linear filtering and 4x MSAA.
- Water/mist/other scene texture animation comes from `FarmModeScript.frames` and `scene_view.c` VRAM copies: preserve 30 Hz keyframe durations, odd-height reset, and PLACE_2C's three repeated strips. Decode motion atlases offline and bake them as native ImageTextures; no runtime disc reads. The user approved smooth water: interpolate the source 2-row scrolling keyframes, crossfade wave frames and add subtle world-space UV ripples on water maps. `source_animation.gdshaderinc` never moves geometry. `tools/verify_water.gd` checks actual GPU interpolation, changes and cycle resets. The game renders at a 60 FPS target with 60 Hz physics; source movement speeds and animation durations do not double.
- The native farm doghouse lintel has two grey untextured triangles exactly covered by the opaque wooden gable at z=-3.4. bake_assets.gd removes just that covered backplate before native baking; preserve the two wooden triangles and their .0072 world-unit area, roof, label and physical ground. render_doghouse.gd -- --verify checks the native result (grey=0, wood=2) and exports a close-up. Do not shift the building or apply a global depth bias to hide coplanar geometry.
- Identical textures share existing semantic resources via the offline `tools/texture_dedup_manifest.json`: 100 compatible PNG/import pairs consolidated (47 runtime, 53 legacy). `texture_dedup.py apply` runs before import/bake and resolves catalogue references; bake_assets.gd resolves source intermediate paths through the same manifest. Never add runtime hashing or a custom texture loader. Seven farm/Yodel motion atlas pairs use shared imported Texture2D resources, uncompressed/no mipmaps/no alpha-border fix/detect_3d conversion disabled to preserve former raw ImageTexture pixels; all other motion atlases keep their existing representation. Preserve palette/STP, per-material blend/shader states, animation records and UVs. `verify_texture_dedup.gd` compares all 46 native scenes against stored pre-consolidation geometry/UV/collision/material fingerprints and checks canonical dependency/resource identity; `texture_dedup.py check` verifies source pixels and alias removal. Do not merge visually distinct import profiles just because the source PNGs match.

## Generated, third-party and legacy paths

- `tools/`: offline conversion and runnable checks. `tools/generated/` contains ignored, regenerable conversion intermediates, not runtime code.
- `reference/` is read-only source reference; `addons/` is third-party code; `verification/` is evidence, not gameplay.
- The old `scenes/farm.tscn`, `scenes/original_farm.scn` and `scripts/farm.gd` are retained for the user's existing editor tabs. The old scene now references canonical farm PNGs instead of 53 redundant legacy texture aliases; three source-identical pairs with different import settings remain distinct. The old script only redirects to `game/world/world.tscn`. Add no new logic to these compatibility paths. Do not rename/close the user's open scene tabs as part of cleanup.
- Runtime assets are native `.scn`, PNG and JSON. Disc reads belong only in the offline importer. Never add a ROM reader, PS1 interpreter or recomp dependency to the Godot runtime.
