# Farm, mines and items

## Soil, crops and mines

- `game/field/` owns farm soil state and hoe results. `farm_field.gd` listens to the actual tool_used signal after the source swing, uses exported picture_grids and player_result_step limits for four directions / five levels (1/2/3/4/6 cells), stops on a refused dig and advances results at 30 Hz. Initial records and real prefab collisions block plots; the collision query uses the 0.4 visual soil grid (0.398 inset query width) so full-cell neighbours do not incorrectly block digging at distant columns; invisible unimported layout placeholders follow the user's existing non-blocking preference. Winter and other areas reject tilling. Soil state is separate from loose-item occupancy, persists across area reloads within the current run, and does not implement full disk saves, greenhouse construction, stamina or random buried objects. A 45x25 R8 state texture updates the existing farm surface shader in place; never rebuild meshes or item batches to hoe. Source CLUTs/31-texel UV corners and column mirror equivalence are verified offline in tools/import_farm_field.py. Preserve transition-owned input locks when cancelling results. Run tools/verify_hoe.gd at 60/120 Hz plus its isolated GPU mode; GPU compares actual Space-key tilled ground to an independent original quad/CLUT, and saves hoe_before/after.png.
- `farm_crops.gd` owns outdoor crop lifecycle on the native 45x25 grid. Use `import_crops.py` after the original sprite extractor, never the disc at runtime. The source 21 seed tools and 22 crop records use source picture grids, stage thresholds, regrow stages, and the day cycle's one 06:00 signal. I opens the direct seed picker, Q selects the seed tool, R cycles seed types, E harvests/stows, and G refills the watering can. During the seed bag equip pose, buffer one Space/X press until the pose ends. Source mode 0x53 uses the seed ANI bank, applies up to nine eligible tiles at animation end, and selects sown/watered-sown soil art. All seed types can be sown outside winter on outdoor tilled or watered soil. Apply seasonal withering on the 06:00 growth tick, as in field_event_dispatch and field_tile_season_result in the original field code. No separate particle emitter is called by that mode. The HUD reports changed plots or why sowing was refused. Seasonal crops clear on rollover and grass grows without watering, yields fodder under the sickle and overwinters. Keep plant records separate from loose items; only non-grass visible plants obstruct movement. Preserve native atlas pivots and the shared soil state texture. `verify_crops.gd` covers all crop records and the normal tool/clock entry points. This stage uses a free seed selector and session-local harvest pouch. Orange Cup uses its spring growth record and greenhouse art on the outdoor grid until the greenhouse is implemented.
- `game/field/mine_field.gd` owns the current native mine dig effect in areas 234/245. Source mine_dig always changes one cell 0.4 ahead regardless of hoe level/charge or winter; use a 10x10 grid from (-2,-2), actual obstruction tests and original mine_retexture_cell clear texture (page 9, CLUT 0x3DE4, UV 131..159 x 0..31). Update a 100-byte R8 state texture in place, never rebuild the map. Keep visits separate from farm soil, preserve state on same-visit reload and clear mine visits on original outdoor entrance location IDs 0xC/0xD (farm_main/mine_clear_grid). This stage implements dug ground only; random loot, exit chance, lower floors and their menu/events remain unimplemented. tools/import_shadow_mine.py is offline and integrated into Import-Assets.ps1; --check verifies source PNG pixels and all 200 source mine cell quads/UVs. verify_mine_dig.gd uses real Space, source reference FT4 GPU samples, four facings, charge/season, obstructions/bounds, repeated digs, stable mesh/texture and visit reset at 60/120 Hz.
