# World, doors and transitions

## Ownership and loading

- `game/world/`: world entry scene, location catalog, navigation/exits and simple navigation prompts. Do not put player animation, camera math, shops, crops or NPC behavior here.
- `location_loader.gd` uses native threaded requests to warm only the current location and direct neighbours (both coast regions count together). warm() only plans/evicts the cache; issue requests from poll() after world._ready completes, at most one map in flight, avoiding concurrent startup prefetch during synchronous scene/script/font initialization. Warm the source action pages for hop ranges 10 and 28 first via PlayerActions' threaded loader so the first jump can use the existing texture cache. Do not synchronously preload the atlas in _ready or start the neighbour queue while hop warmup is pending. Keep BOOT_STAGE markers in world/player startup for diagnosing pre-WORLD_READY hangs. tools/verify_startup.gd checks deferred serial prefetch through GPU, and tools/verify_startup.py repeatedly launches the actual main scene with --debug-collisions on an isolated desktop. Release obsolete cached scenes, consume finished requests and leave headless checks deterministic. HUD refreshes are limited to 10 Hz and a single Windows CJK-capable font avoids per-script fallback draw switches.
- `game/locations/<semantic_name>/`: one original place per folder, its native scene and texture atlases. Use names such as `farmhouse`, `library`, `clinic`; raw source area numbers belong in metadata, never the primary directory name.

## Doors and exits

- Arrival doors must wait for the real capsule to clear their entire hinge sweep before consuming the normal 11-tick hold or closing. source_doors.guard_arrival bounds both leaves by their native mesh hinge radii plus .02 clearance, and tests the actual CollisionShape3D global centre/radius along the outward direction. Pause closing if the player re-enters the sweep; resume once clear. world.gd walks outward only when necessary, for at most 21/30 seconds, with normal collision mask 3 and native walkability/obstacle checks; blocked exits release input and leave the door open. Never disable arrival collision or teleport to force clearance. Keep cancellation cleanup and immediate indoor/stair return working: the narrow-zone compensation checks the shared pure player.has_walkable_ground query as well as capsule test_move, including when stationary. verify_door_exit.gd checks four actual exits, a real blocking wall/input recovery, twin leaves, physical capsule overlap during closure, stationary E return and re-entry while closing at 60/120 Hz and isolated GPU.
- The exterior Yodel Ranch house has two visible risers ahead of its door. Its baked ramp preserves the visible stairs and lets the native capsule reach the existing closed-door stop. Keep the original door access rules and test physical approach from below the stairs.
- Source door hinges live in `source_doors.gd`: 8 turn-units acceleration, 0x420 logical opening limit, 11-tick hold, 30 Hz updates and mirrored twins. doors.c writes the drawn turn before clamping: preserve the 1088-unit displayed peak on tick 16 while internal angle is 1056; keep that drawing during hold. Retriggering an open door adds 5 hold ticks; reopening preserves swing speed. ## Notices and world history

- `game/world/object_notices.json` stores Chinese readings and the original active value-menu and marriage-menu probe zones. Regenerate positions with `tools/import_disc.py <disc> --notices-only`. Z uses the source facing and reach. Active toolbox zones come from the same import and open the existing tool picker when the player faces the chest. Locked doors explain their refusal in the same local notice UI; dismissing it consumes the held interaction.
- `game/world/world_history.gd` owns one chronological journal per run. Records distinguish actions from speech and store stable witness IDs. NPC dialogue filters by those IDs before topic recall, sends only selected records, and does not grant knowledge on retries or map changes. Private dialogue belongs to its two participants. World saves do not exist yet, so a new run starts with an empty journal.

## Coast seam

- Town square and beach share `game/world/coast.tscn` in continuous world coordinates. Beach is translated by (12.4,0,0.8); the shared upper landing is world x=5. The offline coast builder clips duplicate previews into each location's `coast_segment.scn`, retaining one complete beach staircase. Crossing changes the region label without reloading scenes, meshes, player coordinates or camera. The x=5 first riser was duplicated as four exactly coplanar triangles in both source previews. bake_coast.gd gives shared-boundary visible triangles to the beach only; never add a depth bias or change the physical ramps to hide z-fighting. render_coast_seam.gd asserts town=0/beach=4 boundary triangles and GPU samples agree with beach-only drawing. Other areas retain source exits. Coordinate-aware checks use `area_to_world` / `world_to_area`; `tools/verify_coast.gd` must pass three lanes, walk/run, immediate return, stable mesh IDs and continuous floor/camera at 60/120 Hz.
