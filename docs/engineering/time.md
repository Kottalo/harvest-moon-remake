# Clock and sleep

- `game/time/` owns clock/calendar, source subtractive tint and bed menu. `day_cycle_catalog.json` comes from the source place table and zone headers through `tools/import_day_cycle.py`; runtime never reads the disc. The remake advances one game minute per 2 real seconds indoors and outdoors, retaining fractional minutes through area changes. The HUD displays each minute. Overview, dialogue and all modal interfaces leave the clock running. Area and sleep transitions suspend the clock. Natural dawn advances the date in place, including while a modal is open. Dates roll at 06:00, not midnight; 30 days/season, four seasons/year. Choosing sleep returns to the verified farmhouse morning coordinates after the bed animation. This stage does not implement fatigue/crops/animals/seasonal art/save files. Run `tools/verify_day_cycle.gd` plus the isolated `tools/render_day_cycle_check.gd` GPU entry.
- F1's NPC map displays the shared presence data for all 43 areas. It opens with character movement suspended and the clock running, optionally updates character positions live while suspending gameplay input, and restores the prior process state when closed. The walkable silhouettes are baked from offline area geometry with `tools/bake_npc_map.py`.
- `game/time/day_cycle_debug.gd` owns the F1 debug panel, initially hidden, with native OptionButton choices automatic/morning/day/evening/night. day_cycle.debug_period=-1 follows the normal source tint; manual 0..3 previews use its original RGBs immediately, including indoors, without editing time/date or natural tint interpolation. Hiding retains the preview; choose automatic to restore normal area rules. Opening pauses the SceneTree and closing restores the previous pause state, leaving all player input locks untouched. The overlay runs ALWAYS above game/transition UI; F1 ignores echo and also handles the PopupMenu.window_input signal, then hides the popup on close. Keyboard closing uses F1; the mouse close button does not steal gameplay accept keys. Removing an open panel restores its owned pause. verify_day_debug.gd checks native layout, viewport F1 input, popup signals/native index_pressed -> OptionButton selection, five choices, paused movement/tools with a running clock, indoor override/restoration, retained selection and input-lock/pause cleanup. Do not start/stop the user's game to demonstrate it.
