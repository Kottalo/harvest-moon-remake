# Project instructions

## Directory contract

- `game/player/`: player scene, input, movement, ANI playback and shared player assets only. No world/map loading dependencies.
- `player_actions.gd` owns the source ANI action state, charge/release timing and held-item drawing; it emits interaction/tool signals. `actions/action_catalog.json` and its named atlases are extracted offline. Full actions use a 256-pixel common canvas packed with AtlasTexture margins; its origin (128,176) preserves the exact existing (0,53) pivot and pixel_size. Do not trim away the original pose offsets or clip long tool/water effects. `tools/import_player_actions.py --check` compares the original 90 frames pixel-for-pixel after unpacking.
- `game/items/` owns native loose-item pictures and session records. Farm debris is taken from the title's new-game field layout, not invented positions. Pickups, placement/discard and tool hits update those records; do not claim crop growth or animal gameplay from animation playback alone.
- `game/field/` owns farm soil state and hoe results. `farm_field.gd` listens to the actual tool_used signal after the source swing, uses exported picture_grids and player_result_step limits for four directions / five levels (1/2/3/4/6 cells), stops on a refused dig and advances results at 30 Hz. Initial records and real prefab collisions block plots; the collision query uses the 0.4 visual soil grid (0.398 inset query width) so full-cell neighbours do not incorrectly block digging at distant columns; invisible unimported layout placeholders follow the user's existing non-blocking preference. Winter and other areas reject tilling. Soil state is separate from loose-item occupancy, persists across area reloads within the current run, and does not implement full disk saves, crops, greenhouse/mining, stamina or random buried objects. A 45x25 R8 state texture updates the existing farm surface shader in place; never rebuild meshes or item batches to hoe. Source CLUTs/31-texel UV corners and column mirror equivalence are verified offline in tools/import_farm_field.py. Preserve transition-owned input locks when cancelling results. Run tools/verify_hoe.gd at 60/120 Hz plus its isolated GPU mode; GPU compares actual Space-key tilled ground to an independent original quad/CLUT, and saves hoe_before/after.png.
- The user owns item alignment now. `game/items/prefabs/{stone,branch,weeds}.tscn` are the authoritative editable prefabs. GroundSprite controls picture position/Offset/Pixel Size/X-Y scale; Obstruction/FieldFootprint and LooseFootprint control the corresponding box transform and size. The @tool root displays one orange world-oriented box according to Preview Mode; it never billboards with the art. Runtime reads these definitions once, retains three MultiMesh batches, and applies the same box to collision and placement queries. Do not overwrite authored prefab values from the source catalogue or importer, or reset user edits merely to pass source-default regression checks. Keep prefab roots at the logical pivot; edit children for alignment. Preserve later manual edits. On 2026-10-29 the user explicitly requested one exception: centre the branch picture and make all three default item footprints match the full visible soil cell. See prefabs/README.md.
- Static loose items use three cropped MultiMesh batches. Ground ANI comes from farm item-art set 0, slots 0/4/6, range 0; held pictures use the separate per-item files. Never substitute the held PNG for ground drawing: the branch differs by 2 pixels in both axes, stone/weeds by 1 pixel vertically. Preserve the complete ANI canvas offsets. `field_draw_grid` and `estate_draw_records` project (+150,-100,-150) relative to the logical ground point; ground materials' `draw_offset` is Godot (0.15,0.1,0.15), keeping collision at the base and source depth at that anchor. The user-requested branch-only GroundSprite.offset (1,43.05) centres its visible art on the ground cell instead of the original lifted ANI canvas position; preserve stone/weeds picture offsets and all held pictures. `tools/verify_item_offsets_gpu.gd` compares the cropped batches to the original ANI canvas at source projection points across farm corners and 1x/1.44x cameras.
- Stone, branch AND weeds block movement. The user now requests a full visible soil-cell collider for both initial and newly placed items: default FieldFootprint and LooseFootprint are 0.4 x 0.4 in XZ, 0.4 high, centred on the record's visual grid point plus authored prefab offsets. Do not restore source 0.399 initial-grid offsets or 0.2 loose boxes: those were superseded by this explicit user request. The free_position flag still selects the independently editable LooseFootprint. Share shapes by footprint, keep individual bodies and the native high barrier to prevent climbing sprites. The player capsule remains unchanged. tools/verify_item_collision.gd checks full-cell bounds at corners/interior, authored offsets, four approaches/edge lanes, walk/run, empty neighbours, removal and re-placement at 60/120 Hz.
- The user requests a forward interaction detector for assisted placement: an axis-aligned 0.8x0.8 square centred 0.4 ahead follows all four facings. Estimate its free area with 8x8 native shape queries on interaction/release only, excluding the player; require at least 50% free.
